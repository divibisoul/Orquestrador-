# Primordial AI Composition — additive engineering directive

This layer operationalizes a new SOUL rule without changing the existing seven-nucleus topology or converting SARA into N08.

## 1. Individual nucleus as an AI

Each N01–N07 keeps its own native runtime, identity, agents, tools and capability ownership. The primordial profile starts from the native role and evidence recorded before pairwise composition. A profile marked `STRUCTURAL_INDEPENDENT` is a structural assessment, not live inference proof.

SARA is represented separately as a transversal service. It participates in composition (for example N04 + SARA) without becoming an eighth Mesh nucleus.

## 2. Higher-order composition

The existing primordial ledger already contains composition seeds for:
- N02 + N03 + N04 → perceive → reason → act
- N01 + N05 → runtime context → inference/dispatch
- N04 + SARA → tool/artifact execution under governance and audit

The new executable resolver accepts any two or more participants, preserves every participant's native role and primordial essence, and never transfers ownership.

## 3. Evidence states

`SEEDED` / `STRUCTURAL` means a composition is represented and structurally justified by repository evidence.

`REAL_EXECUTION_TRACE` is the next gate. It must be reached by an actual correlated execution, not by a declaration, ping or documentation entry.

## 4. Non-destructive invariant

No old PairComposition, Matrix, registry entry or primordial ledger field is removed. The higher-order resolver and AI profile APIs are additive and use the existing ledger as their source.

## 5. Cooperation with parallel fronts

The resolver is intentionally placed in N07's existing composition authority. Other nuclei remain owners of their native implementations. Parallel fronts can continue adding/reconciling capabilities; this layer consumes their declared evidence rather than copying or replacing their code.
