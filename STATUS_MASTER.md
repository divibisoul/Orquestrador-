## Reading rules

- **STRUCTURAL EVIDENCE** means the source contains an executable implementation path. It does **not** mean live provider execution, cross-nucleus interoperability, or release readiness has been proven.
- **RUNTIME UNVERIFIED** means this audit did not obtain a successful live transaction on the exact current head.
- **CI NOT OBSERVED** means no check runs were returned for the exact current main SHA. It must not be reported as green.
- **BLOCKED_ENV** must be applied only to a transaction proven to require an endpoint/secret/model/device that is unavailable. Repository example placeholders alone do not prove deployed secrets are missing.
- N07's HTTP/OpenAI-compatible ingress is an access interface, not the definition of Mesh. Mesh carries nucleus identity, capability, message, auth, correlation and result; a transport is only its carrier.
- A nucleus may be an AI without being a general-purpose text-generating LLM. Its native intelligence must be assessed against its assigned responsibility. Do not replace a nucleus's identity or specialty by installing an arbitrary LLM.

## Cross-cutting Mesh and correctness issues already identified

1. **N07 response authentication ordering:** current `mesh/peers.go` processes HTTP status before verifying response HMAC. Verify authenticity before interpreting a response as trusted. Reimplement this narrow correction with regression tests; do not cherry-pick a broad PR bundle.
2. **N07 retry identity continuity:** current retry loop creates a new message/trace ID on each attempt. Preserve one operation identity across retries; add a test that asserts the ID is stable.
3. **N01 dual runtime contract:** Node gateway and TypeScript Mesh contract are separate implementations. Add/restore a contract test that exercises both; do not accidentally test one and claim the other is covered.
4. **N05 worker-pool truthfulness:** reconcile code, dependencies, tests and `MESH_STATUS.md` before describing Piscina as active.
5. **N07 CI truthfulness:** Pages/Jekyll failure and the absent current-head Go checks must remain separate states. No green result is inferred from a successful status-report job.
6. **Capability truthfulness:** a declaration, endpoint, resident-agent descriptor or “accepted” envelope is not proof of execution. A capability becomes executable only when its owner handler runs and returns a validated result.
